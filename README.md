# Caesar Cipher

A Python implementation of the Caesar Cipher that allows text to be encrypted and decrypted using a customizable shift value.

## Overview

The Caesar Cipher is a substitution cipher that encrypts text by shifting each letter a fixed number of positions through the alphabet.

For example, with a shift of 3, `A` becomes `D`, `B` becomes `E`, and `C` becomes `F`.

The same process can be reversed to decrypt an encrypted message.

## Features

- Encrypt text using a shift value
- Decrypt encrypted text
- Supports uppercase and lowercase letters
- Preserves spaces and punctuation
- Validates shift values
- Simple and reusable Python functions

## Example

An encrypted message:

> Pbhentr vf sbhaq va hayvxryl cynprf.

Decrypted with a shift of 13:

> Courage is found in unlikely places.

## How to Run

2. Clone this repository.
3. Open the project directory in your terminal.
4. Run `caesar_cipher.py`.
